# Agent guidelines

This repository manages a home lab environment with **Packer**, **Terraform**, and **Ansible**. It builds RHEL images, provisions VMs with Terraform, and configures them using Ansible.

## Repo map (start here)

- `packer/`: Packer templates and kickstarts for RHEL image builds. See `packer/README.md`.
- `terraform/`: VM provisioning (and templates that generate Ansible config). See `terraform/README.md`.
- `ansible/`: Playbooks/roles for post-provision configuration. See `ansible/README.md`.
- `pyproject.toml`: Dev tooling (including `ruff`).

## Safety + security (must follow)

- **Do not commit secrets or site-specific config**:
  - ISO images belong under `packer/iso-files/` and must remain git-ignored.
  - Terraform variable files (`*.tfvars`) are often sensitive and are ignored.
  - Ansible vault content (for example `ansible/group_vars/all/vault.yml`) is ignored; never inline decrypted secrets into playbooks.
- **Avoid destructive infrastructure actions by default**:
  - Do not run `terraform apply`/`destroy` or Packer builds unless explicitly requested.
  - Prefer `terraform plan`, `terraform validate`, and format/lint checks.
- **Generated files**:
  - Treat `inventory/hosts` and `ansible.cfg` as generated by Terraform templates; do not hand-edit generated outputs—edit the Terraform templates instead.

## Formatting + linting (do before finishing)

Prefer running the narrowest relevant checks for the files you touched.

- **Python lint**:
  - `ruff check .`
- **Terraform formatting**:
  - `terraform fmt -recursive`
- **Packer formatting**:
  - `packer fmt -recursive packer/`
- **YAML formatting/lint** (when available in the environment):
  - `yamllint ansible/`

## Making changes (expectations)

- Keep changes minimal and scoped to the request.
- Update the nearest README when behavior or required variables change.
- For templates:
  - Terraform templates live under `terraform/templates/` (`*.tftpl`).
  - Packer shared settings live in `packer/common.pkr.hcl` and OS-specific templates in `packer/rhel*.pkr.hcl`.
